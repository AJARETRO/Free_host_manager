# Free_host_manager

A straight forward plugin to kick idle players and shut down after 15 mins. If players use plugman to shutdown it , the server goes down it with.

## Project setup

This repository is now scaffolded as a Maven Spigot plugin project targeting **Minecraft/Spigot 1.8.8**.

### Included setup files

- `pom.xml` with Java 8 config and Spigot API dependency (`org.spigotmc:spigot-api:1.8.8-R0.1-SNAPSHOT`)
- `src/main/resources/plugin.yml` plugin metadata
- `src/main/java/com/ajaretro/freehostmanager/FreeHostManagerPlugin.java` plugin entry class
